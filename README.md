# Sharpie's Gear Judge - XP Bar

A lightweight, visually dynamic experience bar plugin built natively for **Sharpie's Gear Judge (SGJ)**.

## 🌟 Features

- **Dynamic Tracking**: Automatically scales and tracks your current character experience.
- **Classic Rested Tail**: Renders a clean, translucent blue "tail" extending outward beyond your current XP to visually map exactly where your Rested XP ends.
- **Precision Tooltips**: Hovering over the experience bar provides precise mathematical data, including current XP, XP remaining to level, and exact Rested XP values.
- **Native Integration**: Seamlessly ties into the core SharpiesGearJudge module for a cohesive HUD experience.

## ⚙️ Installation

1. Ensure the core **SharpiesGearJudge** addon is installed.
2. Drop the `SharpiesGearJudge_XP` folder into your `Interface/AddOns` directory.
3. Enable the plugin on your character select screen.
